Подключение

Скачать CSS ↓

Добавьте базовые стили и браузерную сборку. Файлы можно скачать с этой страницы и разместить среди ресурсов темы.

Разметка

Один корневой элемент, трек, список и слайды. Для существующего виджета сохраняйте его классы и оформление.

Инициализация

Вызывайте конструктор после появления разметки в DOM. Слушатели mounted регистрируйте до mount().

ES-модуль

ESM-сборка экспортирует тот же конструктор. CSS подключается отдельно.

Настройки

new Splide(root, options)

Значения в столбце «По умолчанию» относятся к Nano Swipe. breakpoints используют ширину окна. Новые значения можно передать через slider.options = { ... }.

Вместе с зум-галереей

Передайте в noDrag селектор активной сенсорной поверхности. Проверяется элемент, на котором начался жест. Чтобы исключить и обёртку, и вложенные элементы, перечислите оба селектора.

Настройка действует и на копии слайдов в loop. Подключайте зум к каждой обёртке, включая клоны. При обновлении списка подключайте новые обёртки и освобождайте удалённые через API вашей галереи. Для управления нативными сенсорными жестами галерея задаёт собственный touch-action.

Общие значения и data-атрибут

Splide.defaults задаёт настройки будущих экземпляров. Значения data-splide имеют приоритет над настройками конструктора.

Свойства

index — текущий индекс с нуля. length — количество оригинальных слайдов. root — корневой DOM-элемент. options — действующие настройки.

Components.Elements предоставляет root, track, list и массив оригинальных slides. После изменения содержимого списка вызывайте refresh().

События

on · off · emit

Имена можно разделять пробелом или передавать массивом. Для выборочного отключения обработчиков используйте namespace, например move.counter.
