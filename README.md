# Nano Swipe

Компактный горизонтальный слайдер на JavaScript. Исходники и браузерная сборка находятся в этом репозитории. Runtime-зависимостей нет.

Пакет подготовлен для npm, GitHub Releases и CDN. После первой публикации установка выполняется командой `npm install nano-swipe`. Для сборщика доступны `import Slider from 'nano-swipe'` и `import 'nano-swipe/css'`. CommonJS предоставляет `require('nano-swipe').default`.

Браузерные файлы `nano-swipe.min.js`, `nano-swipe.css` и `nano-swipe.min.js.gz` собираются в `browser-build/` и прикрепляются к GitHub Release вместе с npm-архивом. Инструкция первой публикации, OIDC и следующих выпусков находится в [CONTRIBUTING.md](CONTRIBUTING.md).

Документация с восемью живыми примерами, копируемым кодом и справочником API находится в `docs/`. Структура вдохновлена Slick. Для локального просмотра выполните `npm run docs:dev` и откройте напечатанный адрес Local. По умолчанию используется порт 4173, при занятости выбирается следующий свободный. Команда `npm run docs:build` собирает самостоятельную статическую страницу в `.docs-site/`, включая текущую библиотеку и измеренные gzip-размеры. `npm run test:docs` проверяет страницу в Chromium, Firefox, WebKit и мобильном Chromium. [Референс Slick](https://kenwheeler.github.io/slick/)

Текущая версия экспериментальная. Критерий выпуска с подтверждением минимум 81 из 108 полных виджетов пока не выполнен. Матрица `reports/widgets.json` содержит все 108 виджетов, зависимости из `info.json`, вызовы конструктора, настройки, события и причины исключения. 85 виджетов предварительно отобраны для проверки. Наличие кандидата в матрице само по себе не подтверждает совместимость.

Подключение в браузере

```html
<link rel="stylesheet" href="dist/nano-swipe.css">
<script src="dist/nano-swipe.js"></script>
<script>
  const slider = new Splide('.splide', {
    perPage: 3,
    perMove: 1,
    gap: 16,
    breakpoints: { 767: { perPage: 1 } }
  }).mount();
</script>
```

Разметка использует существующие `.splide`, `.splide__track`, `.splide__list`, `.splide__slide`. CSS содержит структурные правила. Оформление стрелок и пагинации предоставляет тема виджета.

ESM-подключение

```js
import Splide from './dist/nano-swipe.mjs';
```

Реализованы `mount()`, `go(number|string)`, `on()`, `off()`, `emit()`, `refresh()`, `destroy(completely = true)`, `is()`, `root`, `index`, `length`, `options` и `Components.Elements.{root,track,list,slides}`. Присваивание `options` объединяет настройки. Поддерживаются `Splide.defaults`, `data-splide`, горизонтальные `slide` и `loop`, клоны, `rewind`, `perPage`, `perMove`, `gap`, `padding`, `autoWidth`, `focus`, `drag`, брейкпоинты с отключением и автоматическим восстановлением, стрелки, пагинация, autoplay и клавиатура.

Справочник поддержанных настроек, методов и событий находится в документации вместе с рабочими примерами.

Для исключения зум-поверхности из свайпа передайте `noDrag: '.zoomix-touch, .zoomix-touch *'`. Селектор проверяется на элементе начала жеста. Второй селектор охватывает потомков. Настройка применяется к loop-клонам и обновляется через `slider.options = { noDrag: '...' }`. Сенсорную поверхность и её `touch-action` настраивает сама галерея.

Воспроизводимые проверки

```sh
npm ci
npx playwright install chromium firefox webkit
npm test
npm run audit:widgets
npm run check:release
```

`npm test` сначала собирает дистрибутив, затем сравнивает его поведение с зафиксированной эталонной реализацией в трёх браузерах. Проверяются индексы, события, классы, ARIA, размеры, положения слайдов, drag, autoplay, обновление настроек, замена DOM и брейкпоинты на ширинах 390 и 1000 px. Отдельные сценарии выполняют неизменённый JS шести промовиджетов на синтетической разметке. Они проверяют пагинацию и обновление настроек из редактора, однако не сертифицируют полные Liquid/SCSS-виджеты.

Отчёт браузерных тестов записывается в `reports/tests.json`. Для аудита требуется локальный каталог `D:/widget_types`. Другой путь можно задать переменной окружения `WIDGET_ROOT`. Синтаксический разбор находит 162 исполняемых конструктора. Предварительный текстовый поиск также учитывал один закомментированный вызов.

В `tests/tvist-regressions.spec.js` адаптированы 12 сценариев из Tvist на коммите `5458032a407965d59dd64ef12f393ad75e31ea14`. Проверяются смена autoWidth, calc-gap, обновление списка, скрытые карточки, переменные ширины на границах loop, повторные destroy/mount, быстрые клики с проверкой заполнения viewport во время анимации, вложенный drag, второй указатель, pointercancel, очистка autoplay и autoplay на брейкпоинтах. Ожидаемые результаты снимаются с эталонной реализации. Различия в численном расчёте геометрии допускаются в пределах 0,25 px.
