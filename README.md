# Nano Swipe

Горизонтальный слайдер на JavaScript без зависимостей. Поддерживает свайпы, бесконечную прокрутку, адаптивное количество карточек, автопрокрутку и управление с клавиатуры.

[Примеры и справочник API](https://vladimirivanin.github.io/nano-swipe/)

## Быстрый старт

Соберите библиотеку из исходников. Для сборки нужен Node.js 22 или новее.

```sh
npm ci
npm run build
```

Подключите CSS и браузерную сборку, добавьте разметку и создайте слайдер после неё:

```html
<link rel="stylesheet" href="./browser-build/nano-swipe.css">

<div id="gallery" class="splide">
  <div class="splide__track">
    <div class="splide__list">
      <div class="splide__slide">Карточка 1</div>
      <div class="splide__slide">Карточка 2</div>
      <div class="splide__slide">Карточка 3</div>
      <div class="splide__slide">Карточка 4</div>
    </div>
  </div>
</div>

<script src="./browser-build/nano-swipe.min.js"></script>
<script>
  const slider = new Splide('#gallery', {
    type: 'loop',
    perPage: 3,
    perMove: 1,
    gap: 16,
    breakpoints: {
      600: { perPage: 1 }
    }
  }).mount();
</script>
```

CSS библиотеки задаёт раскладку. Внешний вид карточек, стрелок и пагинации оформляйте стилями вашего проекта.

## ES-модуль

```js
import NanoSwipe from './dist/nano-swipe.mjs';

const slider = new NanoSwipe('#gallery', {
  perPage: 3,
  gap: 16
}).mount();
```

CSS подключается отдельно: `./dist/nano-swipe.css`.

## Основные настройки

| Настройка | Назначение |
| --- | --- |
| `type: 'slide'` или `'loop'` | Обычная или бесконечная прокрутка. По умолчанию `'slide'`. |
| `perPage` | Число видимых слайдов, целое положительное. По умолчанию `1`. |
| `perMove` | Число слайдов за шаг навигации. Без настройки используется размер страницы, а при `focus` — один слайд. |
| `gap` | Расстояние между карточками: число в px или CSS-значение. |
| `padding` | Отступы по краям трека, чтобы показать часть соседних карточек. |
| `focus: 'center'` | Размещает активную карточку в центре. |
| `autoWidth: true` | Использует ширину карточек, заданную вашим CSS. |
| `speed` | Продолжительность перехода в миллисекундах. По умолчанию `400`. |
| `autoplay: true` | Включает автопрокрутку. `interval` задаёт интервал, по умолчанию `5000` мс. |
| `breakpoints` | Настройки по ширине окна. По умолчанию применяются до указанной ширины включительно. |
| `arrows` и `pagination` | Стрелки и пагинация. По умолчанию включены. |
| `drag: false` | Отключает перетаскивание мышью и пальцем. |

`type` и `autoWidth` задаются до `mount()` и не меняются через брейкпоинты. Для смены режима вызовите `destroy()`, обновите настройки и снова вызовите `mount()`.

Все настройки, методы и события описаны в [документации](https://vladimirivanin.github.io/nano-swipe/).

## Управление

```js
slider.go('>');       // Следующий шаг
slider.go('<');       // Предыдущий шаг
slider.go(2);         // Слайд с индексом 2, отсчёт с нуля

slider.options = { gap: 24 };

slider.on('moved', (index) => {
  console.log('Текущий слайд:', index);
});

slider.refresh();     // После добавления или удаления слайдов в DOM
slider.destroy();    // Удалить управление и восстановить разметку
```

Текущий индекс доступен в `slider.index`, число оригинальных слайдов — в `slider.length`.

## Интерактивное содержимое

Чтобы исключить область и её потомков из свайпа, передайте селектор в настройках:

```js
const slider = new Splide('#gallery', {
  noDrag: '.interactive, .interactive *'
}).mount();
```

В режиме `loop` создаются копии карточек. Для оформления используйте классы, а для событий внутри карточек — делегирование на корне слайдера. Значения полей форм синхронизируются с оригиналами; ID элементов в копиях отличаются.
